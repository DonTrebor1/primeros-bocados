# Primeros Bocados (versión para un solo móvil)

Todo se guarda en el propio móvil (sin servidor, sin cuentas). Funciona sin internet una vez instalada.

## Publicar (una vez)
Son archivos estáticos: sirve cualquier hosting gratuito con HTTPS.
- **GitHub Pages:** sube esta carpeta a un repositorio, en Settings > Pages elige la rama `main` y la carpeta raíz.
- **Netlify Drop:** arrastra la carpeta a https://app.netlify.com/drop (con cuenta gratuita para que el enlace no caduque).

## Instalar en Android
Abre el enlace en Chrome > menú ⋮ > *Instalar aplicación*.

## Copias de seguridad
Más > Ajustes > *Guardar copia* genera un archivo .json (con fotos) que se puede mandar por WhatsApp o Drive. *Recuperar copia* lo restaura.
